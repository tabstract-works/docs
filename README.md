# Tabstract Works: Project Documents

This repository contains public documents for projects developed by **Tabstract Works**.

Each project has its own directory with PDF documents intended for both academic and business audiences.  
The documents are authored in [SATySFi](https://github.com/gfngfn/SATySFi) and automatically built and published via GitHub Actions to GitHub Pages.
